# Forma de trabajo

## Inicio

Leer AGENTS y STATUS, comprobar Git y archivos reales, seleccionar una tarea y definir su resultado y comprobación.

## Desarrollo guiado

Cada paso indica qué se hará, por qué, ruta, contenido o comando y cómo verificarlo. Manuel aplica los pasos salvo encargo de implementación al agente.

No dar por aplicado un archivo enviado por chat. No avanzar sobre un requisito pendiente sin identificarlo.

## Cierre

Revisar diff, ejecutar controles apropiados, actualizar STATUS y documentos afectados, preparar mensaje completo de commit y señalar si falta push, PR o merge.

## Cambio de agente u ordenador

Continuar desde el repositorio actualizado, no desde recuerdos. No editar los mismos archivos simultáneamente desde herramientas distintas. Consultar docs/tooling.md para requisitos y configuración local.
