# Registro de decisiones

Crear un documento por decisión importante usando TEMPLATE.md. No registrar decisiones triviales ni presentar una propuesta como aprobada.

Numeración sugerida: 0001-runtime-and-dependencies.md, 0002-authentication.md, 0003-monitor-scheduling.md.

Estados: propuesta, aceptada, sustituida. Una decisión sustituida enlaza a la nueva.
